# CLAUDE.md

This repo builds an open curriculum for agentic coding fundamentals.

- Read `CONTEXT.md` first. Use its terms everywhere.
- `PLAN.md` holds the current build tasks. Never edit `PLAN.md`.
- `CURRICULUM.md` holds the lesson sequence and every lesson spec.
- Log every decision and every deviation in `DECISIONS.md`.
- Write all course text in ste-style. Use the skill at `.claude/skills/ste-style/SKILL.md`.
- Run `bash scripts/check.sh` before you call a lesson done.
- Put no org-specific content in this repo.
