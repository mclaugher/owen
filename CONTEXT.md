# Glossary

One term for one thing. Use these terms in every document and lesson.

- **Pre-access core** — the shared primer plus lessons A1–A3. A learner completes it before tool access. It requires zero tool access and runs in any browser.
- **Shared primer** — lesson `0000-where-tokens-actually-go`. Its own page. Every track builds on it. A1 recaps it; A1 does not repeat it.
- **Track A / B / C** — Foundations (new users) / Efficiency and Setup Ownership (existing users) / Structured Autonomy (elective).
- **Lesson spine** — the durable body of a lesson. The spine holds principles only.
- **Dated callout** — a boxed lesson element that holds version-sensitive facts (model names, commands, toggles, limits) with the date they were verified.
- **Tier words** — frontier, mid, small. The spine names models by tier, never by product name.
- **First-wins menu** — A1's four starter use cases (stack-trace analysis, refactoring, test generation, codebase questions). Each is an instance of one property: bounded scope, checkable outcome, small context footprint.
- **Verification rule** — more autonomy granted means more verification owed. Stated in A2, applied in A3.
- **Pointer** — the optional "now apply this to your own work" line that ends every lesson. Untracked homework, never required coursework.
- **Quiz** — the 5-question instant-feedback retrieval-practice block that ends every lesson.
- **Learning record** — the Markdown record written after a lesson is generated. It carries one "still shaky on X" item that drives a spaced callback in the next lesson.
- **Persona** — the Markdown learner profile the fork reads in place of a live interview.
- **teach-curriculum** — the fork of the vendored teach skill. It generates one lesson per invocation in CURRICULUM.md order.
- **Practice repo** — the seeded exercise codebase for post-access lessons. Built from publicly available material only. Not part of v0.1.0.
- **Capstone** — the standard end-of-track task. Its result compares against a published baseline range.
- **Baseline range** — the published token range for a capstone, recorded with its exercise config and date. Directional once the model lineup changes.
- **Plugin** — a shareable additive bundle (skills, commands, agents, hooks) a teammate installs on top of their own setup.
- **Dotfiles setup** — a personal whole-profile configuration, switched wholesale. Not a sharing vehicle; a personal practice.
