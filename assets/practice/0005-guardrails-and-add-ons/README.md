# Slugify practice folder

Lesson 0005 works inside this folder.

## What this is

`slugify.py` turns a post title into a slug: the lowercase,
hyphen-separated form of the title that goes in a web address.
`test_slugify.py` holds four tests that define what the program
must do.

## Commands

- Run the program: `python3 slugify.py "Plan -- then build"`
- Run the tests: `python3 -m unittest -v`

## The check

Work in this folder is done when the test run ends with `OK`.
Right now it does not: one test fails, because the program has a
bug. The test is correct. Lesson 0005 tells you what to build
around that failure before anyone fixes it.
