# Persona: Track A new user

The learner profile for the shared primer and Track A lessons. The teach-curriculum skill reads this file in place of the live interview.

## Who

A working engineer. Competent in git and one mainstream programming language. New to agentic coding tools.

## Mission

Decide whether agentic coding tools earn a place in their daily work. Leave each lesson with one habit to apply the same day.

## Prior knowledge

- Uses git daily: branches, diffs, code review.
- Fluent in one mainstream language. Reads others.
- Has used a chat LLM. Has not used an agentic coding tool.

## Disposition

- Skeptical of hype. Trusts mechanisms and numbers over claims.
- Short on time. Budgets 20 minutes per lesson.

## Constraints

- Has no tool access before the pre-access core is complete.
- Reads lessons in a browser, sometimes offline.
