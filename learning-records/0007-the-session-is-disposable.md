# The session is disposable; the files are the work

A6 closed record 0006's shaky item: the learner can now separate the window (which dies with the session and degrades as it fills) from the durable state on disk (which greets every new session). The evidence is a completed two-session handoff: session one read the task and produced one small file, PLAN.md, with the open decisions decided; session two started fresh, read the plan and the instructions file, built the feature, and passed the check — with zero re-explaining across the gap. The learner also holds the three habits as one picture: one task per session, the plan in a file, commits as save points — and can name the helper idea (a second session reads the big thing in its own window and returns a summary) without yet having used one.

Still shaky on: ending a session that is going *badly*. A6 taught the learner to end good sessions on purpose — the task is done, the transcript is weight, start fresh. But every session in A6 behaved. The learner has no trigger yet for the mid-task case: a session that forgets an instruction it was given, repeats an approach that already failed, or states wrong things with confidence. The reflex there is still to keep correcting in place, because mid-task restarting feels like forfeiting the tokens already spent — the learner has also never once looked at what a session actually cost, so "cheaper to restart" is a claim they have to take on faith. A7 opens with a spaced callback to this item: you learned to end finished sessions; now learn to end failing ones earlier, and to read the bill either way.
