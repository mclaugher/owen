Agentic Coding Fundamentals

Pre-access core · v0.1.0 · about one hour total

This is the pre-access core of an open curriculum on agentic coding. It is built for the working engineer: competent in git and one mainstream language, new to agentic coding tools, short on time. The four lessons below need no tool access, no account, and no network. Each page is self-contained and works offline. Each ends with a five-question instant-feedback quiz.

Take the lessons in order. Each one opens where the last one left a question hanging.

The lessons

  1. Where Tokens Actually Go · shared primer · about 10 minutes
    The one mechanism under every habit this curriculum teaches: the context window, how it fills, and what a full window does to the model.
  2. The Mental Model · A1 · about 15 minutes
    Small, focused tasks as the highest-leverage habit; the two dials every tool exposes; four safe first tasks and the one property they share.
  3. Scoping and Modes · A2 · about 15 minutes
    When to plan before code and when to skip it; the four operating modes and how to match mode to risk; the verification rule.
  4. Reviewing Agent Output · A3 · about 20 minutes
    Why agent output is not a colleague's PR; tests as guardrails; the security review you owe every agent-assisted diff, with a flawed diff to practice on.

What the full curriculum adds

The pre-access core is the start of a larger curriculum. Later releases add the rest, built on the same primer:

  • Track A, continued (A4–A6). Owning your setup and the .claude directory, iteration patterns, and failure modes with recovery — the lessons you take once you have tool access.
  • Track B — Efficiency and Setup Ownership. For engineers already using the tools: audit sessions, context hygiene, right-sizing the model and thinking dials, and packaging a setup worth sharing.
  • Track C — Structured Autonomy. An elective on running agents with less supervision: plans and ADRs as durable state, role loops and model routing, and parallel sessions.
  • A practice repo. A seeded exercise codebase for the post-access lessons, built from publicly available material.
