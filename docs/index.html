Agentic Coding Fundamentals

Track A: Foundations · v0.2.0 · eight lessons

This is Track A of an open curriculum on agentic coding. It is built for the working engineer: new to agentic coding tools, short on time. Eight lessons in two phases. The pre-access core needs no tool access, no account, and no network. The applied phase puts an agentic coding tool in your hands, and every exercise file it needs is packed inside the lesson page. Each page is self-contained and works offline. Each ends with a five-question instant-feedback quiz.

Suggested experience. You will get the most out of this course if you are comfortable with a terminal, know git basics, can read code in one language, and have an editor installed. The list is encouragement, not a gate. You can take the course without any item on it.

Take the lessons in order. Each one opens where the last one left a question hanging.

The pre-access core

Four lessons, about one hour total. No tool access required, so you can finish them before your access request clears.

  1. Where Tokens Actually Go · shared primer · about 10 minutes
    The one mechanism under every habit this curriculum teaches: the context window, how it fills, and what a full window does to the model.
  2. The Mental Model · A1 · about 15 minutes
    Small, focused tasks as the highest-leverage habit; the two dials every tool exposes; four safe first tasks and the one property they share.
  3. Scoping and Modes · A2 · about 15 minutes
    When to plan before code and when to skip it; the four operating modes and how to match mode to risk; the verification rule.
  4. Reviewing Agent Output · A3 · about 20 minutes
    Why agent output is not a colleague's PR; tests as guardrails; the security review you owe every agent-assisted diff, with a flawed diff to practice on.

The applied phase

Four lessons, about 20 minutes each plus hands-on practice. Tool access starts here. Each lesson hands you a small practice folder, packed inside the page behind a download button that works offline. Re-downloading the folder resets the exercise.

  1. First Win, Then Make It Yours · A4 · about 20 minutes
    Your first real session fixes a planted bug end to end. Then the instructions file every session reads first, and three permission setups to read and adapt.
  2. Guardrails and Add-ons · A5 · about 20 minutes
    A guardrail is a rule the tool enforces, not a rule the agent reads. Build one, watch it fire and clear. Then judge one add-on against its standing cost.
  3. Small Sessions · A6 · about 20 minutes
    End sessions on purpose: one task per session, the plan in a file, commits as save points. The exercise runs one task across two sessions that never meet.
  4. When Things Go Wrong, and What It Cost · A7 · about 20 minutes
    The warning signs of a session gone bad, the restart rule, and the two bills every session can show you. The finale exercise uses every habit in the course, then reads what it cost.

What comes next

Track A is complete. Later releases add two more tracks, built on the same primer:

  • Track B — Efficiency and Setup Ownership. The efficiency course that lesson 0007 points to, for engineers already using the tools: audit sessions, context hygiene, right-sizing the model and thinking dials, and packaging a setup worth sharing.
  • Track C — Structured Autonomy. An elective on running agents with less supervision: plans and ADRs as durable state, role loops and model routing, and parallel sessions.
